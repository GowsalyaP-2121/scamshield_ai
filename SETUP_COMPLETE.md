## 🔑 Getting Your API Key

To use the application, you need a Google AI API key:

1. **Get API Key**:
   - Visit: https://makersuite.google.com/app/apikey
   - Sign in with Google account
   - Click "Create API Key"
   - Copy the key

2. **Configure in App**:
   - Open your live URL
   - Scroll to "API Configuration" section
   - Paste your API key
   - Click "Save Key"

3. **Start Analyzing**:
   - Enter any suspicious message
   - Click "Analyze Message"
   - Get AI-powered scam detection results!
