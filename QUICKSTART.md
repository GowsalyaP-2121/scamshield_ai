## 📝 Step-by-Step Instructions

### Step 1: Get Your Google AI API Key (5 minutes)

1. Open [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with your Google account
3. Click **"Create API Key"** button
4. **Copy** the API key that appears
5. Keep it safe - you'll need it to test your app

### Step 2: Enable GitHub Pages (2 minutes)

1. Go to your repository: https://github.com/GowsalyaP-2121/scamshield_ai
2. Click the **"Settings"** tab (top right)
3. In the left sidebar, click **"Pages"**
4. Under **"Source"**, select:
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **"Save"**
6. ✨ GitHub will show you: "Your site is live at https://gowsalyap-2121.github.io/scamshield_ai/"

### Step 3: Wait for Deployment (1-2 minutes)

- GitHub is now building and deploying your site
- You can watch progress in the **"Actions"** tab
- Look for a green checkmark ✅ indicating success

### Step 4: Test Your Live Application

1. Open your public URL: **https://gowsalyap-2121.github.io/scamshield_ai/**
2. Scroll down to "API Configuration"
3. Paste your Google AI API key
4. Click "Save Key"
5. Try one of the example messages or enter your own
6. Click "Analyze Message"
7. See the results! 🎉

## 🆘 Troubleshooting

### "Site not found" error?
- Wait a few more minutes for deployment
- Check GitHub Pages settings
- Ensure branch is set to "main"

### API key not working?
- Verify you copied the complete key
- Check for extra spaces
- Generate a new key if needed

### App not loading correctly?
- Clear your browser cache
- Try incognito/private mode
- Check the browser console for errors
